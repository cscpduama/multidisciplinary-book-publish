## 📝 How to Update Information

### 1. Correcting Chapter Titles or Author Names
1. Open the file `index.html` in this directory.
2. Search for the author's name or title you want to fix (e.g., using `Ctrl+F`).
3. Update the text and save the file.

### 2. Uploading or Replacing a Chapter PDF
To add or replace a chapter PDF:
1. Name the PDF file exactly matching the target chapter (e.g. `chapter22.pdf`).
2. Put the file inside the `chapters/` folder.
