## 📂 Folder Structure

* 📄 **`index.html`**
  * The main webpage showing the contributor list, editors, advisory board, and interactive search tool for the first edition.
* 🖼️ **`coverImage_en.png`**
  * The graphic file of the book's front cover.
* 📂 **`chapters/`**
  * The folder where the PDF files are stored.
  * 📄 `chapter1.pdf` to `chapter41.pdf` (The individual chapters).
  * 📄 `finalbook.pdf` (The full book volume).

---

## 📝 How to Update Information

### 1. Correcting Chapter Titles or Author Names
1. Open the file `index.html` in this directory.
2. Search for the author's name or title you want to fix (e.g., using `Ctrl+F`).
3. Update the text and save the file.

### 2. Replacing a Chapter PDF
If you need to update a chapter PDF (e.g. to fix a printing error):
1. Name the new PDF file exactly matching the target chapter (e.g. `chapter5.pdf`).
2. Put the file inside the `chapters/` folder, overwriting the old file.
